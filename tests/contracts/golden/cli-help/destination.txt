Destination catalog: managed and observed aliases (M02)

Usage: heimdall destination [OPTIONS] <COMMAND>

Commands:
  add     Add or update a destination
  list    List destinations (read-only)
  show    Show one destination (read-only)
  remove  Remove a destination. The projection is marked stale; no file changes
  prefer  Choose which mechanism serves an alias: the managed definition or the existing access (M03; takes effect with `setup apply`)
  help    Print this message or the help of the given subcommand(s)

Options:
      --json             Machine output: one JSON envelope on stdout (NDJSON for event streams)
      --non-interactive  Never open a browser, dialog, or terminal prompt (spec §11.3). Owner decisions then exit 3 with `next.decision_ref` and nothing is sent
      --home <DIR>       Override the Heimdall home directory (fixtures and tests) [env: HEIMDALL_HOME=]
  -h, --help             Print help
