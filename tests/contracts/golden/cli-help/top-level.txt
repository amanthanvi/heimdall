Heimdall: set up access once; your terminals, tools, and agents work across environments

Usage: heimdall [OPTIONS] [COMMAND]

Commands:
  setup        Adopt supported local access: preview, apply, roll back or repair the managed OpenSSH projection. Without an action, `apply`
  connect      Convenience connect through the verified client; ordinary ssh also works
  run          Ensure access then launch argv without a shell
  status       Summary of the runtime, open work, and pending owner decisions. Never starts the runtime
  doctor       Passive diagnostics by default; explicit probes only by named level. Never starts the runtime
  tui          Terminal UI
  destination  Destination catalog: managed and observed aliases
  identity     Adopted identities and their interaction declarations
  profile      Profiles: named sets of destination/account pairs
  uninstall    Remove the projection, restore your files, and report what remains
  issuer       The local issuer: its CA key, status, recovery bundle
  enroll       Enroll a destination for managed credentials and manage its enrollments
  connections  Owned connections and their owner-side close
  wsl          WSL distributions Heimdall serves: enable, disable, status
  container    Local Linux-container environments and their binding recipe
  project      Project trust: the trust record of the workspace you are in
  activate     Activate the profile the working directory's workspace names; the shell hook
  shell        Shell integration
  export       Export your portable intent: profiles and destinations, never authority
  import       Import portable intent from an exported bundle; it grants no access
  environment  Remote runner environments: add, invite, join, revoke-client, remove, update, status
  device       This controller device: retire
  route        A destination's approved routes: add, remove, prefer
  transport    The Iroh transport: enable, disable, adopt-roost
  support      Diagnostics for a support request: a bundle of codes and counts, never secrets or free text, previewed before it is written
  state        The local state store: its status, and the attended restore, reset and repair
  inspect      Read-only inspection of runtime state. Never starts the runtime
  access       Access primitives
  operation    Operation observation and control
  decision     Pending owner decisions. Approving or denying needs a terminal and a typed `yes`; the runtime cannot verify that this client prompted (a same-user program can imitate the owner flow)
  time         Owner time confirmation
  service      Per-user runtime control
  schema       Public schemas, the code table, the error reasons and the agent primitives
  help         Print this message or the help of the given subcommand(s)

Options:
      --json             Machine output: one JSON envelope on stdout (NDJSON for event streams)
      --non-interactive  Never open a browser, dialog, or terminal prompt. Owner decisions then exit 3 with `next.decision_ref` and nothing is sent
      --home <DIR>       Use this Heimdall home directory instead of the default [env: HEIMDALL_HOME=]
  -h, --help             Print help
  -V, --version          Print version
