Restore the CA key from a backup (the passphrase is typed on the terminal)

Usage: heimdall issuer restore [OPTIONS] --backup <FILE>

Options:
      --backup <FILE>    The encrypted backup file
      --json             Machine output: one JSON envelope on stdout (NDJSON for event streams)
      --non-interactive  Never open a browser, dialog, or terminal prompt (spec §11.3). Owner decisions then exit 3 with `next.decision_ref` and nothing is sent
      --not-stolen       The backup is not believed stolen
      --home <DIR>       Override the Heimdall home directory (fixtures and tests) [env: HEIMDALL_HOME=]
  -h, --help             Print help

Also the recovery when the issuer reports `issuer_store_access_denied` (on macOS, an ad-hoc-signed build after an update): the CA is restored to a new store item, recorded after a typed `yes`; the old item is kept and listed under orphan store items, to be deleted in Keychain Access (Heimdall never deletes it).
