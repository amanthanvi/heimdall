Remove an enrollment, or a foreign one from a bundle

Usage: heimdall enroll remove [OPTIONS] <ENROLLMENT|--from-bundle <FILE>>

Arguments:
  [ENROLLMENT]  Enrollment ID

Options:
      --from-bundle <FILE>  Remove an enrollment recorded only in this bundle
      --json                Machine output: one JSON envelope on stdout (NDJSON for event streams)
      --marker <MARKER>     The marker of the bundle's enrollment
      --non-interactive     Never open a browser, dialog, or terminal prompt (spec §11.3). Owner decisions then exit 3 with `next.decision_ref` and nothing is sent
      --alias <ALIAS>       The local alias that reaches the destination
      --home <DIR>          Override the Heimdall home directory (fixtures and tests) [env: HEIMDALL_HOME=]
  -h, --help                Print help
