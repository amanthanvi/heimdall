Access primitives

Usage: heimdall access [OPTIONS] <COMMAND>

Commands:
  ensure             Idempotent access preparation
  release            Drop this consumer's reference to a binding
  revoke             Revoke a grant and its descendants
  delegate           Narrower child binding
  pause              Pause automatic activation for a policy, a profile, a workspace or all (owner channel; narrowing)
  resume             Resume automatic activation (widening: needs an owner decision)
  cutoff             Schedule (or clear) a hard stop for a policy, a profile, a workspace or all. An earlier cutoff applies at once; a later one or `--clear` needs an owner decision
  lock-behavior      Choose what a session lock does to a policy's managed grants (narrowing is immediate, widening needs an owner decision)
  connection-policy  Choose what happens to owned connections at the deadline, and whether Heimdall owns a multiplex master
  allow              Owner-initiated review that may widen a workspace's, profile's or policy's standing scope; always creates its own decision
  stop               Stop now: end one work's access, or a policy's, a profile's, a workspace's or all
  default-profile    The profile a new request without one uses: show, set or clear this environment's preference; never authority
  help               Print this message or the help of the given subcommand(s)

Options:
      --json             Machine output: one JSON envelope on stdout (NDJSON for event streams)
      --non-interactive  Never open a browser, dialog, or terminal prompt. Owner decisions then exit 3 with `next.decision_ref` and nothing is sent
      --home <DIR>       Use this Heimdall home directory instead of the default [env: HEIMDALL_HOME=]
  -h, --help             Print help
