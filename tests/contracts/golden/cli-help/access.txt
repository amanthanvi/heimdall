Access primitives

Usage: heimdall access [OPTIONS] <COMMAND>

Commands:
  ensure             Idempotent access preparation (spec §11.3)
  release            Drop this consumer's reference to a binding
  revoke             Revoke a grant and its descendants (spec §6.7)
  delegate           Narrower child binding (M05 demo; model in M01)
  pause              Pause automatic activation for a policy (owner channel; narrowing)
  resume             Resume automatic activation (widening: needs an owner decision)
  cutoff             Schedule (or clear) a hard stop for a policy (spec §6.1). An earlier cutoff applies at once; a later one or `--clear` needs an owner decision
  lock-behavior      Choose what a session lock does to a policy's managed grants (M03; narrowing is immediate, widening needs an owner decision)
  connection-policy  Choose what happens to owned connections at the deadline, and whether Heimdall owns a multiplex master (M03)
  help               Print this message or the help of the given subcommand(s)

Options:
      --json             Machine output: one JSON envelope on stdout (NDJSON for event streams)
      --non-interactive  Never open a browser, dialog, or terminal prompt (spec §11.3). Owner decisions then exit 3 with `next.decision_ref` and nothing is sent
      --home <DIR>       Override the Heimdall home directory (fixtures and tests) [env: HEIMDALL_HOME=]
  -h, --help             Print help
