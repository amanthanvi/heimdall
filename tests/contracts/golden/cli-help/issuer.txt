The local issuer: its CA key, status, recovery bundle (M03; ADR-0008 D3, D4)

Usage: heimdall issuer [OPTIONS] <COMMAND>

Commands:
  init     Create the CA key and its offline backup (terminal only)
  status   Show the issuer's state, CAs and enrollment counts (read-only)
  unlock   Unlock the CA key store (attended)
  rotate   Rotate the CA key
  retire   Retire a CA by fingerprint
  restore  Restore the CA key from a backup (the passphrase is typed on the terminal)
  bundle   Write a recovery bundle
  help     Print this message or the help of the given subcommand(s)

Options:
      --json             Machine output: one JSON envelope on stdout (NDJSON for event streams)
      --non-interactive  Never open a browser, dialog, or terminal prompt (spec §11.3). Owner decisions then exit 3 with `next.decision_ref` and nothing is sent
      --home <DIR>       Override the Heimdall home directory (fixtures and tests) [env: HEIMDALL_HOME=]
  -h, --help             Print help
