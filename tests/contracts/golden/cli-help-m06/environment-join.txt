On the invited device: join from the owner's invitation bundle after confirming the runner's host key and environment ID. `--show-key` prints this device's management key for the owner first

Usage: heimdall environment join [OPTIONS] [BUNDLE]

Arguments:
  [BUNDLE]  The invitation bundle file (`-`: standard input)

Options:
      --json             Machine output: one JSON envelope on stdout (NDJSON for event streams)
      --show-key         Print this device's management key and fingerprint (created when absent), for the owner's `environment invite`
      --non-interactive  Never open a browser, dialog, or terminal prompt. Owner decisions then exit 3 with `next.decision_ref` and nothing is sent
      --home <DIR>       Use this Heimdall home directory instead of the default [env: HEIMDALL_HOME=]
  -h, --help             Print help
