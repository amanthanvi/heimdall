Invite another device's management key to a runner. You confirm its fingerprint here; the runner holds the invitation until it is confirmed there

Usage: heimdall environment invite [OPTIONS] --role <ROLE> --public-key <KEY> <ENVIRONMENT>

Arguments:
  <ENVIRONMENT>
          The runner environment

Options:
      --json
          Machine output: one JSON envelope on stdout (NDJSON for event streams)

      --role <ROLE>
          The role to offer

          Possible values:
          - owner:     Every permission
          - requester: View and request
          - viewer:    View only

      --non-interactive
          Never open a browser, dialog, or terminal prompt. Owner decisions then exit 3 with `next.decision_ref` and nothing is sent

      --public-key <KEY>
          The invited device's management key (the line its `environment join --show-key` printed)

      --home <DIR>
          Use this Heimdall home directory instead of the default
          
          [env: HEIMDALL_HOME=]

      --request-id <ID>
          Reuse the request ID the pending answer named, after confirming at the runner

      --request-epoch <N>
          The restore epoch the request ID was first sent with (the answer's `request_epoch`): give it with the same `--request-id` to retry. Without it, the runner's current epoch is used

      --iroh
          Let the invited device reach the runner over Iroh: it sends its own endpoint ID when it joins (confirmed at the runner with the invitation)

  -h, --help
          Print help (see a summary with '-h')
