The Iroh transport: enable, disable, adopt-roost (M06; ADR-0012 §1, §2, §2.8)

Usage: heimdall transport [OPTIONS] <COMMAND>

Commands:
  enable       Enable the Iroh transport
  disable      Disable the Iroh transport
  adopt-roost  Adopt an existing Pigeons roost as a route (a widening, confirmed locally)
  help         Print this message or the help of the given subcommand(s)

Options:
      --json             Machine output: one JSON envelope on stdout (NDJSON for event streams)
      --non-interactive  Never open a browser, dialog, or terminal prompt (spec §11.3). Owner decisions then exit 3 with `next.decision_ref` and nothing is sent
      --home <DIR>       Override the Heimdall home directory (fixtures and tests) [env: HEIMDALL_HOME=]
  -h, --help             Print help
