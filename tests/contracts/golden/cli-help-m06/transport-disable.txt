Disable the Iroh transport.

Stops serving, destroys the endpoint key and removes every route that names it. It forgets the enrolled clients' endpoints but does not revoke any client: a later enable serves the clients still enrolled. To remove one client's Iroh access permanently, revoke that client.

Usage: heimdall transport disable [OPTIONS]

Options:
      --json
          Machine output: one JSON envelope on stdout (NDJSON for event streams)

      --non-interactive
          Never open a browser, dialog, or terminal prompt (spec §11.3). Owner decisions then exit 3 with `next.decision_ref` and nothing is sent

      --home <DIR>
          Override the Heimdall home directory (fixtures and tests)
          
          [env: HEIMDALL_HOME=]

  -h, --help
          Print help (see a summary with '-h')
