On the runner, in the bootstrap's interactive ssh session: mark this installation a remote runner and enroll the controller's management key as owner, after the owner confirms its fingerprint on this terminal

Usage: heimdall remote init [OPTIONS] --owner-client <CLIENT> --owner-key <KEY>

Options:
      --json                      Machine output: one JSON envelope on stdout (NDJSON for event streams)
      --owner-client <CLIENT>     The client ID the controller records for itself
      --non-interactive           Never open a browser, dialog, or terminal prompt (spec §11.3). Owner decisions then exit 3 with `next.decision_ref` and nothing is sent
      --owner-key <KEY>           The controller's management key (`ssh-ed25519 <base64>`)
      --expect-sha256 <HEX>       The expected SHA-256 of this runner's Heimdall executable (64 lowercase hex): the bootstrap's checksum step; refused before anything is written when it differs
      --home <DIR>                Override the Heimdall home directory (fixtures and tests) [env: HEIMDALL_HOME=]
      --issuer-ca <KEY>           ⟨M06 W3⟩ The controller's CA public key (`ssh-ed25519 <base64>`): trusted for the owner client being enrolled, which also becomes this runner's time source, in the same confirmation. Absent when the controller has no issuer
      --iroh-endpoint <ENDPOINT>  ⟨M06 W3⟩ The controller device's Iroh endpoint ID (64 lowercase hex): the owner client is admitted to this runner over Iroh with it, in the same confirmation. Absent when the controller has no Iroh key. An endpoint already recorded is never replaced
  -h, --help                      Print help
