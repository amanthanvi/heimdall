Stop now: end one work's access, or a policy's, a profile's, a workspace's or all (M05; ADR-0011 §7)

Usage: heimdall access stop [OPTIONS] <--work <WORK>|--policy <POLICY>|--profile <PROFILE>|--workspace|--all>

Options:
      --json                     Machine output: one JSON envelope on stdout (NDJSON for event streams)
      --work <WORK>              Stop this work: its unshared grants are revoked, other work is unaffected
      --non-interactive          Never open a browser, dialog, or terminal prompt (spec §11.3). Owner decisions then exit 3 with `next.decision_ref` and nothing is sent
      --policy <POLICY>          Stop this policy (pause and end now)
      --home <DIR>               Override the Heimdall home directory (fixtures and tests) [env: HEIMDALL_HOME=]
      --profile <PROFILE>        Stop every policy for this profile
      --workspace                Stop the policy of the workspace you are in
      --all                      Stop every policy
      --cwd <PATH>               With `--workspace`: the directory whose workspace is meant (default the working directory)
      --request-id <REQUEST_ID>  With `--work`: the idempotency request ID (a fresh one is minted and reported when absent)
  -h, --help                     Print help
