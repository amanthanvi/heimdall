Print the shell integration script for `zsh`, `bash` or `powershell`.

The script runs the `heimdall` that printed it, by its full path. If you move or reinstall `heimdall` to another path, run `heimdall shell init` again; the old hook stays silent.

Usage: heimdall shell init [OPTIONS] <SHELL>

Arguments:
  <SHELL>
          The shell

          Possible values:
          - zsh:        Zsh
          - bash:       Bash
          - powershell: PowerShell (Windows PowerShell 5.1 and PowerShell 7)

Options:
      --json
          Machine output: one JSON envelope on stdout (NDJSON for event streams)

      --non-interactive
          Never open a browser, dialog, or terminal prompt. Owner decisions then exit 3 with `next.decision_ref` and nothing is sent

      --home <DIR>
          Use this Heimdall home directory instead of the default
          
          [env: HEIMDALL_HOME=]

  -h, --help
          Print help (see a summary with '-h')

To load the hook in every new shell, add one line to your shell's startup file. It names this heimdall by its full path, so no other heimdall found on PATH runs when the shell starts:

  zsh (~/.zshrc):          eval "$(@HEIMDALL_PROGRAM@ shell init zsh)"
  bash (~/.bashrc):        eval "$(@HEIMDALL_PROGRAM@ shell init bash)"
  PowerShell ($PROFILE):   Invoke-Expression ((& @HEIMDALL_PROGRAM@ shell init powershell) -join "`n")
