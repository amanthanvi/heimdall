Ensure access then launch argv without a shell (spec §10.4) (M02)

Usage: heimdall run [OPTIONS] -- <ARGV>...

Arguments:
  <ARGV>...  Argument vector after `--`, passed byte-exact. Never sent to the runtime, journaled or logged

Options:
      --json
          Machine output: one JSON envelope on stdout (NDJSON for event streams)
      --profile <PROFILE>
          Profile to ensure. ⟨M05⟩ Without it, the working directory's workspace, else this environment's default profile (ADR-0011 §3.1); a trust decision is asked on a terminal
      --non-interactive
          Never open a browser, dialog, or terminal prompt (spec §11.3). Owner decisions then exit 3 with `next.decision_ref` and nothing is sent
      --work-id <WORK_ID>
          Work ID
      --home <DIR>
          Override the Heimdall home directory (fixtures and tests) [env: HEIMDALL_HOME=]
      --request-id <REQUEST_ID>
          Idempotency request ID for the ensure and bind (a fresh one is minted and reported when absent). A retry with the same ID never relaunches by itself
      --parent-binding <BINDING>
          M05: run the program with a narrower child binding of this parent binding (ADR-0011 §6): the program gets only the child's signing endpoint and no `HEIMDALL_*` variable. A wider scope or a later deadline is refused (`DELEGATION_EXCEEDS_PARENT`) and nothing is launched
      --scope <DEST:ACCOUNT>
          M05, with `--parent-binding`: the child's `destination:account` pairs (repeatable; a subset of the parent's; default all of them)
      --until <INSTANT>
          M05, with `--parent-binding`: the child's deadline, an absolute RFC 3339 instant not later than the parent's (default the parent's)
      --require-capability <CAPABILITY>
          Required credential capability (repeatable): ssh-authentication, git-signing, agent-forwarding
      --require-destination-scope <LEVEL>
          Minimum destination-scope enforcement: unenforced_intent, client_routing, authenticated_agent_restriction, verified_server_principals, isolated_execution_boundary
      --require-offline-until <INSTANT>
          Credentials must stay usable offline until this RFC 3339 instant
      --require-unattended
          New authentications must need no human interaction until the deadline, including through desktop and vault lock (M02, §5 item 6). `unknown` never satisfies it
      --allow-provider-interaction
          Under `--non-interactive`, accept that the provider (not Heimdall) may show its own approval or unlock dialog; without it, an identity that may need interaction is refused before launch (exit 3)
      --meta-fd <FD>
          Write NDJSON run records to this open descriptor (Unix only; must be a pipe, socket or regular file; set close-on-exec)
      --meta-file <PATH>
          Write NDJSON run records to this new file (created exclusively, owner-only)
  -h, --help
          Print help
