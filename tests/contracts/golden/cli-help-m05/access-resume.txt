Resume automatic activation (widening: needs an owner decision)

Usage: heimdall access resume [OPTIONS] <POLICY_ID|--profile <PROFILE>|--workspace|--all>

Arguments:
  [POLICY_ID]  Policy ID

Options:
      --json               Machine output: one JSON envelope on stdout (NDJSON for event streams)
      --profile <PROFILE>  Every policy for this profile
      --non-interactive    Never open a browser, dialog, or terminal prompt. Owner decisions then exit 3 with `next.decision_ref` and nothing is sent
      --workspace          The policy of the workspace you are in
      --all                Every policy
      --home <DIR>         Use this Heimdall home directory instead of the default [env: HEIMDALL_HOME=]
      --cwd <PATH>         With `--workspace`: the directory whose workspace is meant (default the working directory)
  -h, --help               Print help
