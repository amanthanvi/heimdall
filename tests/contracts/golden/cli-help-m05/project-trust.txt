Trust the workspace's manifest: an owner decision that shows the exact scope

Usage: heimdall project trust [OPTIONS]

Options:
      --cwd <PATH>         The directory (default the working directory)
      --json               Machine output: one JSON envelope on stdout (NDJSON for event streams)
      --non-interactive    Never open a browser, dialog, or terminal prompt. Owner decisions then exit 3 with `next.decision_ref` and nothing is sent
      --profile <PROFILE>  For a workspace without `.heimdall.toml`: the profile to trust it with (default this environment's default profile). With a manifest, it must be the manifest's
      --home <DIR>         Use this Heimdall home directory instead of the default [env: HEIMDALL_HOME=]
  -h, --help               Print help
