Import portable intent from an exported bundle; it grants no access

Usage: heimdall import [OPTIONS] <BUNDLE>

Arguments:
  <BUNDLE>  The exported bundle

Options:
      --json                     Machine output: one JSON envelope on stdout (NDJSON for event streams)
      --yes                      Apply the previewed plan without asking (needed without a terminal)
      --non-interactive          Never open a browser, dialog, or terminal prompt. Owner decisions then exit 3 with `next.decision_ref` and nothing is sent
      --request-id <REQUEST_ID>  Idempotency request ID (a fresh one is minted and reported when absent)
      --home <DIR>               Use this Heimdall home directory instead of the default [env: HEIMDALL_HOME=]
      --request-epoch <N>        The restore epoch the request ID was first sent with (the answer's `request_epoch`): give it with the same `--request-id` to retry. Without it, the runtime's current epoch is used
  -h, --help                     Print help
