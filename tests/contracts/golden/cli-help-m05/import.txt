Import portable intent from an exported bundle; it grants no access (M05; ADR-0011 §2.4)

Usage: heimdall import [OPTIONS] <BUNDLE>

Arguments:
  <BUNDLE>  The exported bundle

Options:
      --json                     Machine output: one JSON envelope on stdout (NDJSON for event streams)
      --yes                      Apply the previewed plan without asking (needed without a terminal)
      --non-interactive          Never open a browser, dialog, or terminal prompt (spec §11.3). Owner decisions then exit 3 with `next.decision_ref` and nothing is sent
      --request-id <REQUEST_ID>  Idempotency request ID (a fresh one is minted and reported when absent)
      --home <DIR>               Override the Heimdall home directory (fixtures and tests) [env: HEIMDALL_HOME=]
  -h, --help                     Print help
