Project trust: the trust record of the workspace you are in (M05; ADR-0011 §2)

Usage: heimdall project [OPTIONS] <COMMAND>

Commands:
  trust      Trust the workspace's manifest: an owner decision that shows the exact scope
  status     Show the workspace, its trust state and its policy (read-only)
  untrust    Withdraw the workspace's trust
  reconcile  Resolve an ambiguous workspace match (for example a re-clone at the same path)
  help       Print this message or the help of the given subcommand(s)

Options:
      --json             Machine output: one JSON envelope on stdout (NDJSON for event streams)
      --non-interactive  Never open a browser, dialog, or terminal prompt (spec §11.3). Owner decisions then exit 3 with `next.decision_ref` and nothing is sent
      --home <DIR>       Override the Heimdall home directory (fixtures and tests) [env: HEIMDALL_HOME=]
  -h, --help             Print help
