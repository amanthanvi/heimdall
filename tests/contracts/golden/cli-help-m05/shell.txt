Shell integration

Usage: heimdall shell [OPTIONS] <COMMAND>

Commands:
  init  Print the shell integration script for `zsh`, `bash` or `powershell`
  help  Print this message or the help of the given subcommand(s)

Options:
      --json             Machine output: one JSON envelope on stdout (NDJSON for event streams)
      --non-interactive  Never open a browser, dialog, or terminal prompt. Owner decisions then exit 3 with `next.decision_ref` and nothing is sent
      --home <DIR>       Use this Heimdall home directory instead of the default [env: HEIMDALL_HOME=]
  -h, --help             Print help
