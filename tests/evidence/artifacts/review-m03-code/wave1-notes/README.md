# M03 wave 1: the integrator's working notes

These are the working files of the M03 wave-1 integrator (Opus 5.5, with seven unit agents, in its own worktree from `9b3984ba`): the brief, the API readings and landed interfaces, the questions and escalations, and the worklog. They were archived on 2026-11-10, after the ADR-0008 §17.17 rulings were implemented, with only the dot prefix dropped from each file name; the worktree path is written `<worktree>` and the home directory `<home>`. The notes' cross-target helper `.m03-wave1-xcheck.sh` became `tools/validation/linux-xcheck.sh` (Linux only; Windows is `tools/validation/clippy-windows.sh`).

They are working notes, not rulings. The rulings on wave 1 are in ADR-0008 §17.17.
