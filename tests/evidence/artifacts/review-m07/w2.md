## 2. New findings

### M07-W2-R01 — Blocking (ADR-0009 §2.1). Roundtrip resize back to the original size before redraw bypasses `stale_geometry` across R01 and U1c.
- **Reason blocking:** Bypasses consent/current-frame guard on user-triggered resize+input ordering, executing durable stops, standing-access changes, operation cancellation, and unprompted outbound probes without drawing a post-resize frame.
- **Where:** `crates/heimdall/src/tui/mod.rs:305`, `:352-368`, `:385-388`; `crates/heimdall/src/tui/worker.rs:175-190`.
- **Problem:** `worker::forward_signals` delivers `SIGWINCH` asynchronously via `worker.events`, whereas `event_loop` polls stdin first (`reader.next(INPUT_WAIT)`) and only checks `stale_geometry(terminal, drawn_size)` via `(now.width, now.height) != drawn`. When a terminal resizes down and back (`120x40 -> 40x5 -> 120x40`, e.g. tiling WM/tmux zoom toggle or stalled/restarted process whose alternate-screen lines 6..40 were cropped at 40x5) before `terminal.draw`, `terminal.size()` still equals `(120, 40)`, `app.begin_frame()` is skipped, and queued keys act on the old `drawn_size`.
- **Probe (temporary PTY tests in `tests/e2e/tui_m07.rs`, reverted):** `SIGSTOP -> resize(5,40) -> 5ms -> resize(40,120) -> input -> SIGCONT` bypassed on attempt 1 with `confirm_redraws=0` for:
  - Stop menu (`yes\r`): `ROUNDTRIP_STOP attempt=1 ensure_ok=false refused=false` (durably stopped work `m07-resize-probe`).
  - Settings (`yes\r` on Pause `pol-ops`): `ROUNDTRIP_SETTINGS pol_ops_paused=Some(true) refused=false footer="pause pol-ops: OK"`.
  - Operation detail (`x`): `U1C_CANCEL_ROUNDTRIP footer="cancel op_...: OK" state="cancelled"`.
  - Probe menu (`Enter` on `network`): `U1C_PROBE_ROUNDTRIP` connected (`network 127.0.0.1:61959: ok (11 ms)`).
- **Smallest fix:** Increment an `AtomicU64` resize generation on `SIGWINCH` (in `forward_signals`) and on `term::Input::Resize`; record the generation read right before `terminal.draw`, and in `Input::Keys` treat any generation change or non-empty `worker.events` `Resize` as stale geometry (`app.begin_frame()`).
- **Test coverage:** Existing `resize_then_yes_before_redraw_stops_nothing` only ends at `(40, 5)` so it misses this; a roundtrip `40x120 -> 5x40 -> 40x120` PTY case fails now and passes once fixed.

### M07-W2-R02 — Low (Nonblocking). `skill_lint.py` strips trailing subcommands after any allowlisted prefix.
- **Reason nonblocking:** Authoring lint only; grants no runtime authority or consent bypass.
- **Where:** `tools/validation/skill_lint.py:167-170`.
- **Problem:** `command()` truncates `path` to the longest matching `ALLOWED` entry for *every* command, not just `inspect <subject>` and `schema show <name>`. As a result, invented commands like `    heimdall tui destination remove <alias>`, `    heimdall decision list approve <id>`, or bogus `    heimdall inspect secrets` pass `skill_lint.lint(...)` with zero findings.
- **Smallest fix:** Restrict line 168–170 truncation to `known in {("inspect",), ("schema", "show")}` with `len(path) == len(known) + 1`, and check `inspect` subjects against a fixed allowlist.
- **Test coverage:** Existing `self_check()` misses trailing tokens after non-operand `ALLOWED` commands; adding negative cases to `self_check()` catches both before and passes after the fix.
