**M07-D-R01 — Gate blocker, proposed freeze precedes its required consumer.** M07 plan §§2 U0/U5/U9, 3 and 6; plan §3 G08 and §5 M07; spec G08, A30, A32.

Leave full A30 blocked on a genuinely unfamiliar participant and the baseline, or amend the milestone explicitly. Prove CLI/TUI standalone with an ordinary access and stop journey in each.

**M07-D-R02 — Wave and gate blocker, successful partial lists alter route enforcement and look complete.** ADR-0013 §9 D2; M07 plan §§2 U1/U3/U6, 6; `crates/heimdall/src/connect_cmd.rs:223,295,639`, `enroll_cmd.rs:319`, `tui/worker.rs:533`.
- With a 200-row default, a late alias can become `NOT_FOUND`. If the final destination is on page 1 and its managed hop on page 2, `route_of` returns no hop and `ManagedConnect` omits the check that the hop pair belongs to the covering profile. The TUI would publish page 1 as a successful catalog. U3 covers list output; U6 only switches the TUI to typed views.
- Land point lookups or shared page traversal with all existing callers before enabling pagination, including route dependencies, enrollment, catalog commands and run/profile/identity/projection resolution. A missing required route dependency must fail closed. Stage TUI pages away from the input thread and show loading or stale data on a later-page failure. Test a cross-page managed hop and the final-row reachability and count.

**M07-D-R03 — Gate blocker, snapshot recovery can still hit the frame limit or silently lose state.** ADR-0013 §5, D2/D4/D6; `crates/app/src/events.rs:548,661`, `crates/app/src/operations.rs:10800`, `crates/ipc/src/session.rs:997`.
- D4 caps operations but leaves pending decisions and serialized bytes unbounded. The count-limited `observe events` page can also exceed 1 MiB. If an omitted operation is settled before the client follows the live `inspect` hint, that inspection is from a different point in time and cannot reconstruct the promised snapshot. The published head cursor is after the replay backlog, so persisting it upon receipt also skips unseen backlog after disconnect.
- Bound query work and bytes for every snapshot section and both observation modes. For large snapshots define boundary-consistent continuation, or explicitly define a partial snapshot and a safe rebuild/resubscribe sequence. Specify how an individual oversized item makes progress, and which cursor to durably checkpoint before the backlog drains. Reuse the existing head/backlog fixture and test an oversized event page and a truncated snapshot under a concurrent change.

**M07-D-R04 — Gate blocker, D5 and D6 do not preserve or finish the event contract.** ADR-0013 §§3, 5, 9; ADR-0006 §8 and §13.9 item 6; `crates/app/src/operations.rs:1005,1020,1053,1073,6241`; `crates/app/src/events.rs:504`; `crates/ipc/src/session.rs:802`.
- D5 claims emitted shapes yet replaces `grant_id` and `policy_id`, drops payload fields such as operation `kind` and decision `expires_at`, and leaves two payload families unspecified. Old persisted rows also contain nullable fields. A schema golden alone cannot catch replay failures. D6 conflicts with §6's A19 recovery wording for lag; stale subscription behavior is unspecified when a client takes a fresh snapshot, and the spec omits strict/non-strict cursor treatment and the existing 500-event backlog cap.
- Derive a discriminated payload schema from every emission and replay sample, preserve wire keys and documented nullability or negotiate a new version. Specify bad/future/foreign cursor behavior in each mode, scope to reader and environment, preserve revision 6 visibility/client revocation, and define unsubscribe or terminal resync behavior and checkpoints. Assert the distinction between lag and trimming at the wire, using existing retention paths.

**M07-D-R05 — Wave blocker, the new retention ceiling changes accepted configuration and retry guarantees.** ADR-0013 §§3, 6 and D16; ADR-0006 §§7.3–7.4 and rev. 6 §18.2 item 7; ADR-0012 §3.10 T-RA3; `crates/runtime/src/config.rs:292`, `crates/store/src/ext.rs:338`.
- A valid `retention.operations = "120d"` can fail startup under the proposed validation. Clamping instead would shorten the future guarantee a caller relies on. §6 also describes only operation-backed keys, but revision 6 has synchronous widening requests with a request ID and a terminal decision result, without an operation row.
- Drop the ceiling for this freeze. Preserve recorded expiry and markers, and document the decision-backed replay and retention rule separately. Enumerate the pending readings to ratify against the final M06 baseline.

**M07-D-R06 — Required G08 completion, pagination has no advertised compatibility boundary.** ADR-0013 §§3, 9 D1/D2/D4/D9/D18; M07 plan §4 skew; `crates/contract/src/request.rs:417`.
- Older runtimes can ignore new request fields under the tolerance rule. Older clients can treat a short paged response as complete. A reader tag alone does not bind a page token to the environment, subject, filters or ordering. A token issued for one list or query could yield a wrong starting position on another.
- Negotiate the changed semantics explicitly and preserve the old mode during the documented compatibility period, or cite the owner-approved pre-release break and test explicit refusal/fallback. Bind tokens to reader (including paired client), environment and canonical query/sort, with immutable unique tie-breaks and fresh authorization. Document the oversized-item result and byte-bounded storage access, including nested collections and environments. Clarify when deprecated versions can actually be removed and how the negotiated version selects the serializer.

**M07-D-R07 — Required G08 completion, the IPC authentication design is incomplete.** ADR-0013 §§1, 8, D12; M07 plan §4; ADR-0006 §2.1; `crates/ipc/src/unix.rs:213`; `crates/heimdall/src/service_cmd.rs:364`.

On Windows, status reads an advertisement and then its connect path re-reads it, so a restart can mix endpoint and hello identity if D12 uses the first record.
- Adopt ADR-0006 §2.1 explicitly, including owner permissions/ACL, both directions of endpoint checks, local-only namespace and the same-user residual. Return the endpoint used for the verified hello, and have the wrapper verify the peer and expected environment. Keep control, signing and issuer discovery separate. Keep the native foreign-owner rows blocked until executed.
